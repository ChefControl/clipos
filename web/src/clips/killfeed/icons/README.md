# CS2 killfeed icons

CS2's own deathnotice and equipment icons (Valve's artwork), shown in the clip page's
killfeed panel and kill marks. They're Valve's property and not covered by clipos's MIT
licence; see `NOTICE` at the repo root. Obtained through Juknum/counter-strike-icons (by
way of the training repo's copy); named as the killfeed analysis names them: weapons by
CS2 class name (`ak47.svg`), modifiers by modifier (`headshot.svg`, `through_smoke.svg`,
...). `suicide.svg` is the deathnotice skull.
